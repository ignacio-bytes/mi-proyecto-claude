## Cómo ver la presentación en VS Code

1. Abre esta carpeta en VS Code (`Archivo → Abrir carpeta...`).
2. Instala la extensión **Live Preview** (de Microsoft, id: `ms-vscode.live-server`) desde la pestaña de extensiones (`Ctrl+Shift+X`).
3. Haz clic derecho sobre `docs/presentacion-estudio-de-mercado.html` → **Show Preview** (o abre el archivo y pulsa el icono de vista previa arriba a la derecha).
4. Navega con las flechas `↑` `↓` del teclado, `AvPág`/`RePág` o haciendo scroll.

Alternativas:
- **Live Server** (id: `ritwickdey.LiveServer`): clic derecho → *Open with Live Server* (se abre en tu navegador).
- Sin extensiones: abre el archivo `.html` directamente con doble clic desde el explorador de archivos — funciona en cualquier navegador, no necesita servidor.

Para el estudio en Markdown: ábrelo en VS Code y pulsa `Ctrl+Shift+V` (vista previa de Markdown).
